# 패턴 — Patterns

컴포넌트를 묶어서 화면과 흐름을 만드는 방법. 새 페이지는 아래 **페이지 틀 6종** 중 하나에서 시작한다.

---

## 1. 앱 구조 — 상단 바 **[결정]**

데스크톱은 위에 붙은 **얇은 반투명 상단 바**(52px)를 쓴다 (apple.com식, `layout.css`의 `data-layout="bar"`).
macOS 앱의 사이드바 구조는 검토했지만 상단 바를 유지했다 → [decisions.md](decisions.md).

```
┌──────────────────────────────────────────────────────────────────┐
│ Labsidian │ 홈 그래프 논문 스터디 사람 │      🔍  [학기]  [✎ 쓰기]  🔔  (나) │
└──────────────────────────────────────────────────────────────────┘
  앞: 브랜드     가운데: 내비게이션             뒤: 검색 · 학기 · 주요 동작 · 알림 · 내 메뉴
```

**규칙**
- 내비게이션 항목은 6개 이하, 짧은 명사. 지금 화면의 항목은 강조(세그먼트 선택 모양)로 표시.
- **주요 동작은 하나**: "쓰기". 상단 바에서 강조색을 쓰는 유일한 요소.
- 바 뒤로 콘텐츠가 지나간다 (`main { padding-top: var(--top-h) }`). 그래프는 화면 맨 위부터 그린다.
- 바 바로 아래에 붙는 줄(홈 피드 탭)은 불투명 바탕 + 아래로 사라지는 스크롤 가장자리 효과. 글 위에 떠 있는 유리 캡슐을 두지 않는다.
- 폰(≤760px): **iOS 방식** — 위에는 얇은 불투명 한 줄(브랜드·검색·학기·쓰기·알림·내 아바타), 섹션은 **아래 탭 바** 5개(홈·그래프·사람·논문·스터디). 내 페이지는 오른쪽 위 아바타에서 연다 (탭은 5개까지 **[HIG]**). 홈 인디케이터 영역은 `env(safe-area-inset-bottom)`만큼 띄운다.

## 2. 페이지 틀

### A. 목록 페이지 — 논문, 스터디 목록, 가이드 목록, 읽을 목록, 분야·방법론

```
[페이지 머리]  Large Title + 부제(Body · label-2)                 [주요 버튼]
[세그먼트]     논문 | 분야·방법론 | 핵심 논문 가이드
[도구줄]       [목록 필터 ......]  [정렬 ▾] [분야 ▾] [연도 ▾]       논문 312편
[목록]         ─ 행 ─ 행 ─ 행 …  (60개씩, 아래에 "더 불러오기")
```
- 폭 `.page` (1180). 목록은 `.ui-list` 안의 행 또는 카드 그리드(가이드·스터디: `auto-fill, minmax(260–320px, 1fr)`).
- 필터 상태는 주소에 남긴다 (`#/papers?q=…`) — 뒤로 가기·공유가 되도록.
- 결과 개수를 도구줄 끝에 회색 숫자로.

### B. 상세 페이지 — 논문, 사람, 스터디, 가이드, 주제

```
‹ 논문                                                     ← 뒤로 (돌아갈 화면 이름)
[머리]  Title 1 제목
        메타 (Callout · label-meta): 저자 · 학회 · 연도
        태그들                                        [동작 버튼들] [⋯]
┌─────────────────────────────────┬──────────────────┐
│ 본문 1fr                         │ 사이드 340 (고정) │
│  초록 (읽는 폭 672)               │  카드: 스터디     │
│  다이어리들                       │  카드: 읽은 사람  │
│                                 │  카드: 비슷한 논문 │
└─────────────────────────────────┴──────────────────┘
```
- 폭 `.page.wide` (1280). 사이드는 `position: sticky`로 상단 바 아래에 붙는다.
- 900px 이하에서는 사이드가 본문 아래로.
- 주제 페이지의 사이드는 그래프 서랍과 같은 렌더 함수를 쓴다. 사람 페이지는 예외 — 아래 "사람 페이지".
- 스터디 상세는 머리가 큰 "히어로"형 (제목 + 일정 + 참가자 묶음) + 할 일 카드 + 세그먼트 탭.

#### 사람 페이지 (프로필) — 서랍과 다른 배치 **[결정]**

```
‹ 사람
[아바타 56] 이름 (Title 1)                          [그래프에서 보기] [비교하기]
            역할 줄 (Title 3) · 숫자 세 칸
[카드] 연구 지형   지도 지역 로즈 + 범례  |  방법론 로즈 + 범례     ← 토글 없이 양쪽
[카드] 관심 변화   줄 = 학기 (학기를 고르면 그 학기의 달)
┌──────────────────────────────┬──────────────────┐
│ 다이어리 (diaries.js 목록)      │ 세부 분야 · 비슷한 사람 │
└──────────────────────────────┴──────────────────┘
```
- 역할: **이 사람은 무엇을 읽어왔고 관심이 어떻게 바뀌었나.** 모두에게 같은 화면(내 것이어도 읽기 전용), 전체 기간.
- 서랍은 같은 내용의 요약(훑어보기), 페이지는 큰 화면에 맞춘 배치. 서랍 렌더 함수를 사이드에 넣지 않는다.

### C. 대시보드 — 홈, 내 페이지, 사람들

- **내 페이지 = 이번 학기 작업 공간**: 학기 진행 · 쓰기 달력 · 할 일(초안, 읽을 목록, 받은 댓글, 다가오는 스터디) · 내 다이어리 관리(편집·삭제·내보내기). 남에게도 보이는 초상(연구 지형·관심 변화)은 두지 않고 "내 프로필"로 잇는다.

- 카드 그리드. 섹션 제목은 Title 2, 카드 제목은 Title 3.
- 숫자 하나를 크게 보여줄 때(이번 학기 다이어리 수)는 Large Title 강조형 + 아래 설명.
- 홈: 피드(1fr) + 오른쪽 사이드 카드(340, 고정). 피드 위 세그먼트는 상단 바 아래에 붙는다.
- 한 카드에 차트 하나. 차트 규칙은 [data-viz.md](data-viz.md).

### D. 편집 — 다이어리 쓰기, 새 스터디

```
[머리]  Large Title
┌──────────────────────────────┬──────────────────┐
│ 폼 카드 (최대 820)             │ 도움 사이드 340    │
│  라벨 / 입력 …                 │  중복 경고         │
│                              │  비슷한 논문        │
│              [취소] [게시]     │                  │
└──────────────────────────────┴──────────────────┘
```
- 버튼은 폼 끝에 **취소 왼쪽 · 주요 동작 오른쪽**. 화면 하단에 고정하지 않는다 **[HIG macOS]**.
- 쓰던 내용은 자동으로 임시 저장하고, 돌아오면 안내줄로 알려 준다.
- 폼 규칙은 §6.

### E. 전체 화면 — 그래프

- 캔버스가 창 전체. 컨트롤은 모두 **떠 있는 유리**: 위 툴바(색 기준·필터·찾기), 왼쪽 아래 범례, 오른쪽 아래 확대·전체 보기, 아래 타임라인.
- 노드를 누르면 오른쪽 서랍(인스펙터). 서랍이 열리면 가운데 정렬 요소는 남은 공간 기준으로 옮긴다.
- 폰: 범례는 접히고 서랍은 전체 화면 시트.

### F. 관리 — 관리자

- 세그먼트(멤버 · 태그 · 학기 · 쉬는 날 …) + 표(`.ui-table`) + 표 위의 추가 폼.
- 파괴적 동작(병합·삭제)은 알림으로 확인.

### 공통: 페이지 머리

| 변형 | 쓰는 곳 | 구성 |
|---|---|---|
| 기본 | 목록·대시보드 | Large Title + 부제 |
| 동작 있음 | 스터디·가이드 목록, 비교 | 기본 + 오른쪽 주요 버튼 |
| 아바타 | 사람·내 페이지 | 아바타 56 + Title 1 + 메타 + 버튼 줄 |
| 상세 | 논문 | 뒤로 + Title 1 + 메타 + 태그 + 버튼 줄 |
| 히어로 | 스터디 상세 | Title 1 + 일정·장소 + 참가자 묶음 + 상태 필 |

제목 크기를 페이지마다 따로 정하지 않는다 (지금 `.page-head h1`, `.dp-head h1`, `.st-hero h1`이 각자 28px로 정의됨 → 토큰으로).

## 3. 세 가지 상태 — 모든 화면이 갖춘다

| 상태 | 보여줄 것 | 컴포넌트 |
|---|---|---|
| **빈 상태** | 왜 비었는지 + 다음 할 일 | `.ui-empty` / `.compact` |
| **불러오는 중** | 0.3초 넘으면 스피너 + 무엇을 불러오는지 | `.ui-spinner`, 버튼 `.is-loading` |
| **오류** | 무엇이 안 됐는지 + 어떻게 하면 되는지 + (가능하면) 다시 시도 버튼 | `.ui-empty`(아이콘 `triangle-alert`) 또는 토스트 |

- 조건 때문에 결과가 없는 것("필터에 맞는 논문이 없어요")과 아직 아무것도 없는 것("아직 다이어리가 없어요")을 구분한다. 앞의 것은 **조건 바꾸기**, 뒤의 것은 **만들기**를 다음 행동으로 준다.
- 차트는 데이터가 모자라면 빈 문자열을 돌려주지 말고, 언제 보이는지 알려 준다 ("다이어리가 15편 넘으면 보여요").

## 4. 내비게이션과 주소

- 화면마다 주소가 있다 (`#/paper/<id>`, `#/study/<id>?tab=notes`). 탭·필터 상태도 주소에 남겨 뒤로 가기가 동작하게 한다.
- 다른 화면으로 가는 것은 `<a href>`, 동작은 `<button>`.
- 서랍·시트·스포트라이트는 주소를 바꾸지 않는다. Esc나 바깥 누르기로 닫힌다.

## 5. 확인과 되돌리기

```
동작이 되돌릴 수 있나?
 ├─ 예  → 바로 실행 + 토스트 "~했어요 [실행 취소]"         (읽을 목록에서 제거, 태그 빼기, 반응 취소)
 └─ 아니오
     ├─ 내 것만 사라짐   → 알림: "~를 삭제할까요?" + 결과 설명 + [취소] [삭제]
     └─ 다른 사람에게 영향 → 알림: 영향을 설명에 적음 ("참가자에게 알림이 가요") + [취소] [마치기]
```

- 알림을 자주 띄우면 아무도 읽지 않는다. 되돌릴 수 있는 일에는 띄우지 않는다 **[HIG]**.
- 실행 버튼 이름은 제목의 동사와 같게 ("병합할까요?" → [병합]).

## 6. 폼

- 라벨은 위, 도움말·오류는 아래 (§ [components 4](components.md#4-입력)).
- 필수 항목이 대부분이면 선택 항목에만 "(선택)"을 붙인다. 반대면 필수에 표시.
- 같은 줄에 두 입력을 놓을 때는 관련 있는 것만 (날짜 + 시간, 저널 + 연도). 폰에서는 한 줄에 하나.
- 오류는 제출할 때 한꺼번에 보여주고, 첫 오류 입력으로 포커스를 옮긴다. 입력 중에는 형식 검사만.
- Enter: 한 줄 입력에서는 제출, 여러 줄에서는 줄바꿈 (⌘/Ctrl+Enter로 제출).
- 제출 중에는 버튼 `.is-loading`, 성공하면 토스트 + 결과 화면으로.

## 7. 반응형

| 폭 | 바뀌는 것 |
|---|---|
| ≥ 901 | 기본 (2단, 데스크톱 글자) |
| ≤ 900 | 2단 → 1단, 카드 그리드 열 줄어듦 |
| ≤ 760 (폰) | iOS 글자 크기 · 누르기 영역 44 · 상단 바 두 줄 · 서랍 = 전체 화면 시트 · 팝오버 = 아래 시트 · 표 = 카드형 목록 |

- 기준점은 이 둘만 쓴다 ([foundations.md §4-3](foundations.md#4-3-화면-폭-기준점-결정)).
- 마우스 호버에만 있는 정보는 터치에서 탭으로 열린다.

## 8. 키보드

| 키 | 동작 |
|---|---|
| `/` · ⌘K / Ctrl+K | 전역 검색 |
| Esc | 맨 위 층 닫기 (메뉴 → 팝오버 → 시트 → 서랍 순) |
| ↑ ↓ · Enter | 메뉴·검색 결과·목록에서 이동과 실행 |
| ⌘/Ctrl + Enter | 여러 줄 입력에서 제출 |
| Tab | 모달 안에서는 모달 안에서만 돈다 |

- 단축키는 메뉴 항목 오른쪽에 회색으로 보여 준다.
- 포커스 링을 지우지 않는다.
