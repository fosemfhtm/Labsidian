# 데이터 시각화 — Data visualization

HIG는 차트의 큰 원칙만 준다. 이 문서는 Labsidian의 그래프·차트에 쓰는 **색 체계와 차트별 규칙**을 정한다.

---

## 1. 원칙

1. **실제 기록만 그린다.** 다이어리·태그·지도·함께 읽은 논문에서 나온 값만. 지어낸 점수를 만들지 않는다.
2. **색은 뜻이 있을 때만 쓴다.** 계열 구분이 필요 없으면 한 색(강조색 또는 회색)으로 그린다.
3. **차트 하나에 메시지 하나.** 카드 제목이 그 메시지를 말한다 ("관심 분야가 이렇게 바뀌었어요" 대신 "월별 관심 분야").
4. **테마를 따라간다.** 라이트·다크·고대비에서 모두 읽혀야 한다. 색은 그릴 때 토큰에서 읽는다.
5. **글자가 데이터보다 크지 않게.** 라벨은 작고 조용하게, 데이터가 앞에 나선다.

---

## 2. 색 체계

| 종류 | 무엇에 | 색 출처 | 테마 따라감 |
|---|---|---|---|
| **사람 색** | 사람 노드, 아바타, 달력, 비교 막대 | 멤버가 자유 선택 (hex) — **예외** | ❌ |
| **분야·방법론 색** | 분야/방법론 태그, 관심 변화 막대, 로즈 꽃잎 | 시스템 색 이름 (`"teal"`) **[목표]** | ✅ |
| **지도 영역 색** | 그래프의 영역(클러스터) 윤곽·라벨 | 시스템 색 이름, 큰 영역 단위로 배정 **[목표]** | ✅ |
| **순서 색** | 출판 연도 | 시스템 색 5단계 사이 보간 (blue → cyan → green → yellow → orange) | ✅ |
| **학회 색** | 그래프의 학회 색 모드 (상위 10개) | 시스템 색 10개 순서대로 **[목표]** | ✅ |
| **없음·기타** | 태그 없음, 기타 묶음, 연도 미상 | `--gray` / `--gray2` — **이 뜻으로만** | ✅ |
| **흐리게** | 필터에서 빠진 노드·꽃잎 | `--fill` 또는 `--label-4` | ✅ |
| **단일 계열** | 진행 막대, 스파크라인, 막대 하나짜리 | 강조색 또는 해당 사람 색 | — |

**규칙**
- 데이터에 **hex를 저장하지 않고 시스템 색 이름을 저장한다** (`color: "indigo"`). 그릴 때 `rgb(var(--indigo))`로 바꾸면 테마를 따라간다. 사람 색만 예외.
- 색을 더 만들지 않는다. 차트 하나에 계열이 많으면 **상위 N개만 색, 나머지는 "기타"(회색)**로 묶는다 (로즈 8개, 관심 변화 6개). 태그 자체의 색은 축 안에서 12색을 돌려 쓴다.
- 같은 대상은 어디서나 같은 색: 분야 "자율주행"은 태그·로즈·관심 변화 막대에서 모두 같은 색.
- 사람 색은 사람을 가리킬 때만. 사람 서랍의 "세부 분야" 막대처럼 *분야*를 보여주는 곳에서는 분야 색을 쓴다.
- 흐림·테두리·라벨 색을 다크 전용 값으로 하드코딩하지 않는다 (지금 `graph.js`의 `#2b2b38`, `#3a3a48`, `#16161e`).

**구현** (2026-10-03)
- `store.js`의 `dataColor()`가 분야·방법론·지도 영역 색을 `rgb(var(--이름))`으로 바꿔 둔다. 그래서 HTML에서는 `style="background:${색}"`만 써도 테마를 따라간다.
- 옛 빌드의 팔레트 hex(GitHub·Tokyo Night 계열)는 불러올 때 이름으로 옮긴다. 태그는 **축 안의 순서대로 12색**을 받는다 (옛 팔레트는 11색이라 같은 색이 겹쳤음).
- 한 축에 태그가 12개를 넘으면 색이 겹친다. 겹쳐서 헷갈리면 관리자 → 태그에서 색을 고른다 (시스템 색 목록). MCP `admin_create_tag`/`admin_rename_tag`도 색 이름을 받는다.
- 캔버스(그래프)는 `graph.js`의 `hex()`가 그릴 때 실제 값으로 바꾸고, 테마가 바뀌면 `lab:theme` 이벤트를 받아 `readTheme()` → 다시 칠한다. 새로 고침하지 않는다.
- 사람 색과 옛 팔레트 변환표는 hex가 필요해서 `store.js`의 `// design-lint: off … on` 구간에 있다.

---|---|
| 팔레트 네 계열 혼재: 사람(Material → Apple hex 재매핑), 분야(GitHub hex), 지도 영역(Tokyo Night hex), 그래프 학회(Tokyo Night hex) | 사람 외에는 모두 시스템 색 이름 |
| `build_site.py`의 `TOPIC_COLORS`·`CLUSTER_COLORS`·`METHOD_COLORS`, `graph.js`의 `VENUE_PALETTE`·`YEAR_STOPS` | 시스템 색 이름 목록으로 교체 |
| 임시 회색 `#888`, `#555`, `#9da7b3`, `#4a4a58`, `#55556a` | `--gray` / `--gray2` |
| 그래프가 테마를 불러올 때 한 번만 읽고, 바꾸면 페이지를 새로 고침 | 테마가 바뀌면 다시 칠하기 (`fade()` 캐시 비우고 refresh) |
| 사람 색 기본 배정에 gray 포함, 재매핑 충돌(갈색·인디고·청록 두 명씩) | 기본 배정에서 회색 제외, 충돌 없는 순서 |

## 3. 글자와 라벨

| 요소 | 스타일 |
|---|---|
| 차트 카드 제목 | Title 3 |
| 축 눈금, 그래프 노드 라벨 | Footnote (10) · `--label-2` |
| 범례 | Callout (12) · `--label`, 개수는 `--label-meta` + `tabular-nums` |
| 값 라벨 (막대 끝 숫자) | Callout · `tabular-nums` |
| 그래프 영역 이름 | 큰 영역 Headline · 작은 영역 Subheadline 알약 |

- 캔버스(sigma)에서도 글꼴·크기를 토큰에서 읽는다 (지금 `graph.js`에 글꼴 목록과 13 / 10.5 / 12px가 하드코딩).
- 데스크톱 최소 10px. 10px로도 안 들어가면 라벨을 줄이거나 호버 때만 보여 준다.

## 4. 차트 종류별 규칙

### 네트워크 그래프 (`graph.js`, `#/graph`)
- 노드 = 논문(지도 위치), 사람 노드 + 사람–논문 선, 배경 = 지도 영역 윤곽.
- 색 기준: 처음 읽은 사람(기본) · 출판 연도 · 학회. 범례가 색 기준을 따라 바뀐다.
- 호버: 이웃 강조 + 나머지 흐리게. 클릭: 서랍. 범례 항목 클릭 = 그 항목만 보기, 더블클릭 = 확대.
- 필터 방식 "흐리게 / 숨기기"는 모든 필터에 똑같이 적용.
- "2명 이상 읽음" 테두리는 `--label` 색으로 그리고, 범례 문구도 색 이름("흰 테두리") 대신 "테두리 = 2명 이상 읽음"으로.

### 로즈(극좌표 꽃잎) 차트 (`viz.js`)
- 축 = 분야 또는 방법론 (3개 이상일 때만). 꽃잎 색 = 분야·방법론 색, 빈 칸 = `--fill-4`, 연구실 평균 = `--label` 점선.
- 크기 세 가지만: 220(서랍·연구실 카드) · 180(비교) · 120(사람 카드).
- 꽃잎과 범례 행은 서로 연결 (하나에 올리면 둘 다 강조). 축을 고르면 다른 꽃잎은 흐리게.
- 다이어리 15편 미만이면 빈 상태 문구 ("다이어리가 15편 넘으면 보여요"). 축이 3개 미만일 때도 조용히 사라지지 말고 같은 문구.

### 가로 막대 (`bars()`, `app.js`)
- 항목 이름 왼쪽, 막대 가운데, 값 오른쪽 (`tabular-nums`). 트랙 `--fill-3`, 높이 6, 끝은 완전 둥글게.
- 막대 색 = 그 항목의 색 (분야면 분야 색). 많이 → 적게 순서.

### 비교 막대 (`people.js`)
- 가운데 축을 기준으로 두 사람이 양쪽. 막대 색 = 두 사람의 색. 큰 쪽 값을 굵게.

### 쌓은 막대 — 관심 변화 (`me.js`)
- 100% 가로 막대, 기간(월·학기)마다 한 줄. 상위 6개 분야만 색, 나머지는 "기타"(`--fill`), 태그 없음은 `--gray`.
- 범례 칩을 누르면 아래 다이어리 목록이 걸러진다 — 막대 칸을 눌러도 같다.
- 데이터가 없으면 "—" 대신 빈 상태 문구.

### 히트맵 — 쓰기 달력 (`me.js`)
- 평일만, 칸 = 하루. 칸 색 = 사람 색, 진하기 = 그날 다이어리 수. 진하기는 요소 투명도 대신 `color-mix()`로 (고대비에서 바탕과 섞이지 않게).
- 공휴일 = 빨간 테두리, 연구실 쉬는 날 = 회색 빗금, 오늘 = `--label` 테두리.
- 범례(적음 → 많음), 월 표시, 연속 기록 문구. 칸을 누르면 그날의 툴팁 + "이 날짜로 쓰기".

### 진행 막대 — 학기 목표 (`me.js`), 가이드 읽음 (`guides.js`)
- 트랙 `--fill-3`, 채움 강조색(가이드 완료는 `--success`). 높이 4–8.
- 표시선: 70%(`--separator`), 90%(`--star`), "지금쯤 이만큼" 표시는 `--label`.

### 스파크라인 (`viz.js`)
- 큰 숫자 뒤의 옅은 배경 그림. 사람 색 28% 채움, 축·라벨 없음. 데이터가 없으면 그리지 않는다 (장식이므로 빈 상태 불필요).

## 5. 공통 규칙

**범례**
- 계열이 둘 이상이면 항상 범례. 범례 항목 = 색 점 + 이름 + (선택) 개수.
- 범례 항목을 누르면 **그 계열만 보기**로 통일한다 (그래프·로즈·관심 변화 모두).

**툴팁** — 하나의 컴포넌트 `.ui-tooltip`
- 진한 유리, 둥글기 8, 안쪽 여백 8·10. 제목(Headline) + 값 줄(Callout).
- 마우스: 올리면 나타남. 터치: 탭하면 나타나고 다른 곳을 탭하면 사라짐. 클릭으로 고정할 수 있는 툴팁(달력)은 고정 상태에서 동작 버튼을 보여 준다.
- SVG `<title>`은 접근성 이름으로만 쓰고 툴팁으로 쓰지 않는다.

**빈 상태**
- 데이터가 모자라면 차트 자리에 `.ui-empty.compact`로 언제 보이는지 알려 준다. 빈 문자열 `""`이나 "—"를 돌려주지 않는다.

**접근성**
- 색만으로 구분하지 않는다: 범례 이름, 호버 라벨, 필요하면 무늬(빗금)를 함께.
- 그래픽 대비 3:1 (선·점과 바탕).
- SVG에 `role="img"`와 요약 `aria-label` ("자율주행 12편, 강화학습 8편 …").
- 동작 줄이기 설정이면 물리 애니메이션 없이 바로 배치, 타임랩스는 수동 넘기기로.
