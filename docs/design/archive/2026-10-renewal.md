## 0. "Apple 디자인을 완벽하게 적용"의 범위

**가져오는 것** — HIG의 *원칙과 규칙*: 텍스트 스타일 체계, 시스템 색과 의미 색(label·background·fill·separator), 라이트/다크, 머티리얼(Liquid Glass 포함), 컴포넌트 규칙(버튼 역할, 시트·팝오버·알림, 탭 바·사이드바, 목록), 접근성 기준.

**가져올 수 없는 것** (라이선스·상표, 원문 확인)
| 항목 | 웹에서 사용 | 근거 |
|---|---|---|
| SF Pro / SF Mono / New York 폰트 파일 | ❌ 웹폰트로 올리기 금지 | Apple Font License: "solely for creating mock-ups… may not embed" |
| SF Symbols 아이콘 | ❌ (SVG 복사·비슷하게 다시 그리기 포함) | Xcode/SDK 약관 §2.10, SF Symbols 라이선스 |
| CSS 시스템 글꼴 `-apple-system`, `system-ui` | ✅ — Apple 기기에서는 사용자 OS의 SF로 그려짐 | Apple 포럼 공식 답변, WebKit 블로그 |
| Apple 로고·UI 키트 이미지·기기 프레임 | ❌ | Apple 상표 가이드라인 |
| Apple 웹사이트/제품 UI를 픽셀 단위로 흉내 | ⚠️ 피함 ("imitate the distinctive… web site design" 금지) | 같은 가이드라인 |

→ 목표는 **"Apple 앱처럼 느껴지는, HIG 규칙을 지킨 Labsidian"**이지 Apple 제품의 복제가 아니다. 대체재: 폰트 **시스템 글꼴 + Pretendard**(OFL, 한글), 아이콘 **Lucide**(ISC).

**HIG 디자인 원칙 (2026-06 개정)**: Purpose · Agency · Responsibility · Familiarity · Flexibility · Simplicity · Craft · Delight — 화면마다 "이 요소가 꼭 필요한가(Simplicity), 익숙한 패턴인가(Familiarity)"를 검수 기준으로 쓴다.

### 3-3. 머티리얼 (Liquid Glass)
- HIG: 유리는 **컨트롤·내비게이션 층에만**(사이드바·툴바·탭 바·팝오버·알림), **콘텐츠(카드·리뷰)에는 쓰지 않는다**, "아껴 쓴다".
- 일반(Regular): 흐림 + 밝기 보정 → 상단 툴바·메뉴·팝오버·알림·시트. 웹 구현 [결정, Apple 사용 수준에 맞춤]:
  - 바탕을 많이 비치게(틴트 라이트 흰색 38% / 다크 26%), `blur(14px) saturate(190%) brightness(1.04)`
  - 위쪽 빛 반사(sheen 그라데이션) + 가장자리 하이라이트(rim, 위 1px 밝은 선)
  - 바는 화면 가장자리에서 떨어져 **떠 있는 캡슐**, 버튼은 유리 캡슐로 묶음, 주요 동작만 강조색 유리
  - 글이 많은 유리(메뉴·알림·시트)는 틴트를 진하게(라이트 74% / 다크 56%)
  - 폰 시트도 가장자리에서 떠 있는 둥근 유리
- 투명(Clear): 그래프 위 떠 있는 컨트롤(확대 버튼·범례) — 밝은 배경 위면 35% 어둡게 깔기(HIG).
- 바 배경을 칠하지 말고 콘텐츠와 겹치는 가장자리에만 "스크롤 가장자리 효과"(그라데이션 페이드).
- 유리에는 색이 없다 — 색은 **주요 버튼 하나의 바탕**에만.
- `prefers-reduced-transparency: reduce`이면 불투명 바탕으로.
- ⚠️ 그래프 화면(WebGL) 위 큰 `backdrop-filter`는 성능 비용 → 그래프 위는 작은 컨트롤에만, 실측 후 적용.

### 3-4. 레이아웃·간격·모서리
- 간격 [결정]: 4 · 8 · 12 · 16 · 20 · 24 · 32 · 44 (8pt 기반). 화면 여백 폰 16 / 데스크톱 20 **[외부: UIKit 기본 여백]**.
- 읽기 폭: 리뷰·노트 본문 최대 ~672px **[외부: readable content guide]** → 지금 820px보다 좁게.
- HIG 컨트롤 주변 여백: 테두리 있는 컨트롤 ~12pt, 없는 것 ~24pt.
- **동심원 모서리**(HIG): 안쪽 반지름 = 바깥 반지름 − 안쪽 여백, 최소값 보장. 단계 [결정]: 시트/큰 카드 20 · 카드 14 · 컨트롤(버튼·입력) 10 · 칩·배지 완전 둥글게.
- 그림자 [결정]: 경계선 대신 면 색 차이 + 아주 옅은 그림자 2단계(카드, 떠 있는 것).

### 3-5. 모션
- HIG는 시간·곡선 수치를 주지 않음 → [결정] 짧은 피드백 150ms, 화면 전환·시트 300ms, 감속 `cubic-bezier(.2,.8,.2,1)`, 스프링 느낌은 살짝만.
- "자주 하는 동작은 애니메이션하지 말 것", "움직임만으로 정보를 전하지 말 것".
- `prefers-reduced-motion`: 이동·확대 대신 페이드, 그래프 물리 애니메이션은 즉시 배치.

### 3-6. 누르기 영역
- 폰 44×44px 이상(HIG iOS 기본), 데스크톱 최소 28×28(macOS 기본). 지금 작은 버튼(👍, ✕, ↑↓, 링크 버튼) 대부분 미달 → 영역만 넓히기.

## 4. 컴포넌트 — 지금 → HIG 규칙

| 지금 | HIG 컴포넌트 | 바꿀 점 |
|---|---|---|
| 상단 바 + 메뉴 링크 | **사이드바**(데스크톱) / **탭 바**(폰) | 탭 바는 이동만(동작 X), 5개 이하, 항상 보이게, 빈 섹션도 숨기지 않고 설명. 사이드바 2단계까지 |
| 헤더의 쓰기·학기·알림·내 메뉴 | **툴바** | 앞(제목/뒤로)·가운데·뒤(검색·알림·**주요 동작 1개**) 3구역, 그룹 3개 이하, 글 대신 아이콘, "뒤로"는 표준 화살표 |
| 버튼(primary/기본/링크/danger) | **버튼 역할** normal·primary·cancel·destructive | 한 화면에 눈에 띄는 버튼 1–2개, 우선순위는 크기 말고 스타일로, 파괴적 동작은 primary 금지, 라벨은 동사로 시작, 누름 상태 필수, 처리 중엔 버튼 안 스피너 + "게시하는 중…" |
| `confirm()` (삭제·마치기) | **알림(alert)** | 제목+설명+버튼 최대 3개, "취소" 왼쪽·실행 오른쪽, 버튼 이름은 구체 동사("삭제"), 되돌릴 수 있는 삭제엔 알림 쓰지 않기 → 되돌리기 토스트 |
| 홈·스터디·관리 탭 | **세그먼트 컨트롤** | 같은 너비, 글자만 또는 아이콘만, 5개 이하, 명사 |
| ⋯ 관리 메뉴 | **메뉴** | 동사 라벨, 그룹 구분선, 파괴적 항목 맨 아래 빨간색, 하위 메뉴 1단계 |
| 알림 목록·학기 선택 팝업 | **팝오버**(데스크톱) / **시트**(폰) | 하나만, 중첩 금지, 경고에 쓰지 않기 |
| 스터디 일정 수정 모달·비밀번호 | **시트** | 취소(왼쪽)·완료(오른쪽) 짝, 폰은 아래에서 올라오는 시트 + 손잡이 |

| 피드 옆 카드·관리자 목록 | **목록(그룹형)** | 그룹 머리말·꼬리말, 드릴다운은 꺾쇠(›), 선택 행 강조 |
| 체크박스·옵션 | **토글/체크박스** | 폰 목록 행 안에서는 스위치, 데스크톱 설정은 체크박스, 색만으로 상태 표시 금지 |
| 알림 빨간 숫자 | **배지** | 빨간 타원 + 흰 숫자, 중요한 것에만 |
| "아직 없어요" 문구 | **빈 상태** | 다음 할 일 버튼을 항상 함께 |
| 첫 로그인 비번 변경 | **온보딩** | 짧게, 필요한 순간에 설명 |
| 진행(업로드·불러오기) | **진행 표시** | 가능하면 확정형, "불러오는 중…" 같은 모호한 문구 대신 무엇을 하는지 |

## 7. 위험·한계
- **복제 오해**: Apple 웹/제품 UI를 그대로 흉내 내지 않고 HIG 규칙을 따른 고유 디자인으로. 로고·SF Symbols·Apple 이미지는 쓰지 않음.
- **비 Apple 기기**: 윈도/안드로이드에서는 SF 대신 Pretendard로 보임(Inter 기반이라 가장 비슷한 대안).
- **유리 효과 성능**: WebGL 그래프 위 큰 블러는 느릴 수 있음 → 실측 후 범위 조절.

- **의미 색 값**: Apple이 공개하지 않은 값은 iOS 27 Figma 키트로 다시 맞춤.
