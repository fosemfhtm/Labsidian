# 글쓰기 — Writing

화면의 모든 글자에 대한 규칙. 문구는 i18n 키(`t("key")`)로만 넣는다 (§7).

---

## 1. 목소리

- **차분하고 짧게.** 동료에게 말하듯, 꾸밈 없이.
- **문장은 해요체.** "게시했어요", "조건에 맞는 항목이 없어요". 합니다체·반말은 쓰지 않는다.
- **라벨은 명사형.** 버튼·메뉴·탭·표 머리·입력 라벨·필 — "저장", "참가자", "7일 늦게".
- 한 덩어리 안에서 섞지 않는다: 빈 상태 문장은 해요체("아직 없어요"), 표 칸의 짧은 상태값만 명사형("없음").
- 사용자를 탓하지 않는다: "잘못 입력했어요" 대신 "비밀번호가 맞지 않아요".
- 느낌표·이모지·✓를 쓰지 않는다. 기쁨은 문장이 아니라 결과로 보여 준다.

---

## 2. 용어집

**프로젝트마다 채운다.** 화면에 나오는 대상 이름은 하나로 정하고, 같은 대상을 다른 말로 부르지 않는다. 아래는 형식을 보이는 예다.

| 쓴다 | 쓰지 않는다 | 뜻 |
|---|---|---|
| **게시물** (예) | 포스트, 글 | 사용자가 올린 기록 하나. 세는 단위 "개" |
| 멤버 · 관리자 (예) | 유저, 어드민 | |

- 대상마다 세는 단위(§5)와 영어 대응(§6)도 이 표에 함께 정한다.
- 약어(PDF · URL · AI)는 그대로 쓴다.
- 사람을 부를 때: "{이름} 님" — **님 앞을 띄운다**.

---

## 3. 동작어 표

Apple 한국어 UI 방식: **짧은 동작어**, 대상이 필요하면 "대상 + 동작어" **[결정]**.

| 동작 | 쓴다 | 쓰지 않는다 | 비고 |
|---|---|---|---|
| Save | **저장** | 수정 저장, 노트 저장, 저장하기 | |
| Edit | **편집** | 수정, 고치기 | 창이 열리면 "편집…" |
| Delete | **삭제** | 지우기 | 데이터가 사라질 때만 |
| Remove | **제거** | 빼기, 목록에서 빼기 | 목록·묶음에서만 빠지고 원본은 남을 때 |
| Add | **추가** | 올리기, 담기 | "질문 추가", "목록에 추가" |
| Post | **게시** | 게시하기, 남기기, 올리기 | 글·댓글·질문을 남에게 보이게 할 때 |
| Cancel | **취소** | | |
| Done | **완료** | | 시트의 오른쪽 위 |
| Close | **닫기** | | |
| Undo | **실행 취소** | 되돌리기 | 토스트 |
| New | **새 ~** | ~ 열기, ~ 만들기 | "새 프로젝트", "새 게시물" |
| Join | **참가** | 참가하기 | |
| Rename | **이름 변경** | 제목 고치기 | |
| Merge | **병합** | 확인 | |
| Translate | **번역** | | |
| Share | **공유** | | |
| Export | **내보내기** | | |

- 버튼 이름은 그 버튼이 하는 일 그대로. "확인", "예", "OK"는 쓰지 않는다 (알림의 실행 버튼 포함).
- 누르면 입력이 더 필요한 창이 열리는 버튼·메뉴 항목에는 "…" — "일정·장소 수정…" **[HIG macOS]**.
- 삭제(데이터가 사라짐)와 제거(목록에서만 빠짐)를 섞지 않는다.

## 4. 문구 틀

| 종류 | 틀 | 예 |
|---|---|---|
| **확인창 제목** | ~할까요? | 이 게시물을 삭제할까요? |
| **확인창 설명** | 결과를 한두 문장 | 댓글도 함께 지워지고 되돌릴 수 없어요. |
| **확인창 버튼** | 취소 + 제목의 동사 | [취소] [삭제] |
| **토스트 (성공)** | ~했어요 | 게시했어요 · 목록에 추가했어요 |
| **토스트 (실패)** | ~하지 못했어요. + 할 일 | 저장하지 못했어요. 잠시 뒤 다시 시도해 주세요. |
| **빈 상태 (처음)** | 아직 ~가 없어요. + ~해 보세요. | 아직 메모가 없어요. 회의가 끝나면 누구든 정리해 보세요. |
| **빈 상태 (조건)** | ~에 맞는 ~가 없어요. + 조건 바꾸기 | 조건에 맞는 항목이 없어요. 필터를 줄여 보세요. |
| **빈 상태 (작게)** | 한 문장 | 새 알림이 없어요 |
| **오류 (입력)** | 무엇이 + 어떻게 | 비밀번호는 6자 이상이어야 해요 |
| **오류 (시스템)** | 무엇이 안 됐는지 + 할 일 | 서버에 연결하지 못했어요. 새로 고침해 보세요. |
| **진행** | ~하는 중… | 번역하는 중… · 비슷한 항목 찾는 중… |
| **플레이스홀더** | 예시 또는 범위 | 예: 회의실, Zoom · 문서·사람·프로젝트 검색 |
| **권유** | ~볼까요? | 이번 주 회고를 써 볼까요? |

- 빈 상태의 두 문장은 마침표로 잇는다. " — "로 잇지 않는다.
- 개발자용 정보(파일 이름, 서버 실행 명령, 오류 원문 `e.message`)는 화면에 쓰지 않고 콘솔에 남긴다.
- 확인창의 결과 설명은 제목에 붙이지 않고 `message`에 넣는다 (`AppUI.confirm(title, { message, … })`).

## 5. 표기

**날짜와 시간** **[결정]**

| 상황 | 표기 |
|---|---|
| 방금 일어난 일 (알림·피드·댓글) | 방금 · 5분 전 · 3시간 전 · 어제 · 6일 전 → 7일부터는 날짜 |
| 날짜 (올해) | 10월 2일 |
| 날짜 (다른 해) | 2025년 10월 2일 |
| 요일이 중요할 때 (일정) | 10월 3일 (토) 14:00 |
| 월 단위 | 2026년 10월 |
| 표·내보내기·정렬용 | 2026-10-02 |
| 마감 | D-3 · 오늘 · 3일 지남 |
| 등록 시점 | 7일 늦게 · 2일 미리 |

- 상대 시간 함수는 하나만 쓴다. 날짜는 `Intl.DateTimeFormat`으로.

**숫자와 단위**
- 천 단위 쉼표: 1,234. 숫자 열·개수는 `tabular-nums`.
- 세는 단위는 용어집(§2)에 정한다 — 예: 사람 **명**, 질문·댓글·태그 **개**, 회차 **회**.
- 숫자와 단위는 붙인다: 12개, 3명. 라벨과 숫자는 띄운다: 댓글 12개, 질문 3.

**문장 부호**
- 말줄임: "…" (U+2026) 한 글자. "..." 금지.
- 나열: 가운뎃점 "·" (제목·작성자·키워드).
- 인용: “ ” (곧은따옴표 " " 대신).
- 범위: 3–5 (줄표 en dash).

## 6. 영어 (EN)

- 모든 문구는 KO/EN 두 벌. 영어는 Apple 영어 UI를 따른다: 버튼·메뉴·제목은 **Title Case** ("New Project", "Edit Schedule…"), 문장은 Sentence case.
- 용어집(§2)의 대상마다 영어 대응을 하나로 정한다.
- 상대 시간: "just now · 5 min ago · 3 hr ago · yesterday".

---

## 7. i18n 규칙

- 문구는 i18n 사전에 넣고 `t("key", {vars})`로 쓴다. 코드에 한국어·영어 문장을 직접 쓰지 않는다 (`"(untitled)"`, `lang === "ko" ? … : …` 같은 분기 금지).
- 키는 `모듈.뜻` (`post.delQ`, `list.empty`). 공통 동작어는 `act.*`로 한 번만 정의하고 재사용한다 — `act.save`, `act.delete`, `act.cancel` …
- 변수 자리는 `{name}`. 조사가 바뀌는 곳은 "(으)로", "을(를)" 대신 문장을 바꿔 피한다.
- 쓰지 않는 키는 지운다.
