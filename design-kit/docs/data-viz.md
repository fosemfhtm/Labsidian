# 데이터 시각화 — Data visualization

HIG는 차트의 큰 원칙만 준다. 이 문서는 그래프·차트에 쓰는 **색 체계와 차트별 규칙**을 정한다.

---

## 1. 원칙

1. **실제 기록만 그린다.** 사용자가 남긴 기록·태그·관계에서 나온 값만. 지어낸 점수를 만들지 않는다.
2. **색은 뜻이 있을 때만 쓴다.** 계열 구분이 필요 없으면 한 색(강조색 또는 회색)으로 그린다.
3. **차트 하나에 메시지 하나.** 카드 제목이 그 메시지를 말한다 ("관심 분야가 이렇게 바뀌었어요" 대신 "월별 관심 분야").
4. **테마를 따라간다.** 라이트·다크·고대비에서 모두 읽혀야 한다. 색은 그릴 때 토큰에서 읽는다.
5. **글자가 데이터보다 크지 않게.** 라벨은 작고 조용하게, 데이터가 앞에 나선다.

---

## 2. 색 체계

| 종류 | 무엇에 | 색 출처 | 테마 따라감 |
|---|---|---|---|
| **사용자가 고르는 색** (예: 사람 색) | 사람 노드, 아바타, 달력, 비교 막대 | 사용자가 자유 선택 (hex) — **예외** | ❌ |
| **분류 색** | 분류 태그(주제·종류), 쌓은 막대, 로즈 꽃잎 | 시스템 색 이름 (`"teal"`) | ✅ |
| **영역 색** | 그래프의 영역(클러스터) 윤곽·라벨 | 시스템 색 이름, 큰 영역 단위로 배정 | ✅ |
| **순서 색** | 연도처럼 순서가 있는 값 | 시스템 색 5단계 사이 보간 (blue → cyan → green → yellow → orange) | ✅ |
| **범주 색** | 개수가 많은 범주의 색 모드 (상위 10개, 예: 출처) | 시스템 색 10개 순서대로 | ✅ |
| **없음·기타** | 태그 없음, 기타 묶음, 값 미상 | `--gray` / `--gray2` — **이 뜻으로만** | ✅ |
| **흐리게** | 필터에서 빠진 노드·꽃잎 | `--fill` 또는 `--label-4` | ✅ |
| **단일 계열** | 진행 막대, 스파크라인, 막대 하나짜리 | 강조색 또는 해당 사용자 색 | — |

**규칙**
- 데이터에 **hex를 저장하지 않고 시스템 색 이름을 저장한다** (`color: "indigo"`). 그릴 때 `rgb(var(--indigo))`로 바꾸면 테마를 따라간다. 사용자가 고르는 색만 예외.
- 색을 더 만들지 않는다. 차트 하나에 계열이 많으면 **상위 N개만 색, 나머지는 "기타"(회색)**로 묶는다 (로즈 8개, 쌓은 막대 6개).
- 분류 태그 자체의 색은 한 분류 축 안에서 **순서대로 12색**을 돌려 쓴다. 한 축에 태그가 12개를 넘으면 색이 겹친다 — 겹쳐서 헷갈리면 관리 화면에서 시스템 색 목록 중에서 고르게 한다 (아무 색 고르기를 두지 않는다).
- 같은 대상은 어디서나 같은 색: 분류 하나는 태그·로즈·쌓은 막대에서 모두 같은 색.
- 사용자 색은 사람을 가리킬 때만. 한 사람의 *분류* 분포를 보여주는 막대처럼 분류를 보여주는 곳에서는 분류 색을 쓴다.
- 흐림·테두리·라벨 색을 다크 전용 값으로 하드코딩하지 않는다.

### 2-1. 사용자가 고르는 색 — 예외 **[결정]**

[foundations.md §2-5](foundations.md#2-5-사용자가-고르는-색--예외-결정)를 따른다. 요약:
- 표시용으로만 (노드·계열·달력 칸·범례 점·아바타 바탕). 그 색으로 글자를 칠하지 않는다.
- 그 색 위의 글자는 흰색/검정 중 대비가 큰 쪽을 자동으로.
- 기본 배정에서 회색을 뺀다 (회색 = 없음·기타). 기본 배정 순서에 같은 색이 두 번 나오지 않게 한다.
- 테마·고대비를 따르지 않는다.

### 2-2. 구현 방법

- 데이터 색 이름을 `rgb(var(--이름))` 문자열로 바꾸는 함수를 하나 두고 모든 차트가 쓴다. 그러면 HTML에서는 `style="--c: ${색}"`(또는 `background`)만 써도 테마를 따라간다. JS 인라인 `style=`에는 이런 데이터 색과 동적 크기(막대 폭 등)만 넣는다.
- **캔버스·WebGL 차트**는 CSS 변수를 이해하지 못한다. 그릴 때 `rgb(var(--x))`를 `getComputedStyle`로 읽어 실제 값(hex)으로 바꾸고, 테마가 바뀌면 `window`의 `'app:theme'` 이벤트(`AppUI.setTheme`이 보냄)를 받아 색을 다시 읽고 다시 칠한다. 테마를 바꿀 때 새로 고침하지 않는다. 바뀐 색으로 만든 캐시(흐린 색 등)도 함께 비운다.
- 사용자 색 팔레트처럼 hex가 꼭 필요한 데이터 표는 `// design-lint: off (이유)` … `// design-lint: on` 구간에 넣고, 그 위치를 [decisions.md](decisions.md#프로젝트-결정)에 적는다. 옛 데이터에 hex 색이 있으면 불러올 때 이름으로 옮기는 변환표를 두고, 그 표도 같은 구간에 넣는다.

```js
window.addEventListener('app:theme', () => { readColors(); redraw(); });
```

## 3. 글자와 라벨

| 요소 | 스타일 |
|---|---|
| 차트 카드 제목 | Title 3 |
| 축 눈금, 그래프 노드 라벨 | Footnote (10) · `--label-2` |
| 범례 | Callout (12) · `--label`, 개수는 `--label-meta` + `tabular-nums` |
| 값 라벨 (막대 끝 숫자) | Callout · `tabular-nums` |
| 그래프 영역 이름 | 큰 영역 Headline · 작은 영역 Subheadline 알약 |

- 캔버스에서도 글꼴·크기를 토큰에서 읽는다 (글꼴 목록과 px 크기를 JS에 하드코딩하지 않는다).
- 데스크톱 최소 10px. 10px로도 안 들어가면 라벨을 줄이거나 호버 때만 보여 준다.

## 4. 차트 종류별 규칙

### 네트워크 그래프
- 노드 = 항목(위치는 지도·배치 결과), 필요하면 사람 노드 + 사람–항목 선, 배경 = 영역 윤곽.
- 색 기준을 바꿀 수 있다 (예: 사람 · 순서 값 · 범주). 범례가 색 기준을 따라 바뀐다.
- 호버: 이웃 강조 + 나머지 흐리게. 클릭: 서랍. 범례 항목 클릭 = 그 항목만 보기, 더블클릭 = 확대.
- 필터 방식 "흐리게 / 숨기기"는 모든 필터에 똑같이 적용.
- 특별한 표시 테두리(예: "2명 이상")는 `--label` 색으로 그리고, 범례 문구도 색 이름("흰 테두리") 대신 뜻으로 ("테두리 = 2명 이상").
- 배치 계산은 화면에 그리며 여러 번 돌리지 말고 화면 밖에서 한 번에 계산한 뒤 한 번 그린다. 다른 페이지로 가면 계산을 멈춘다.
- 폰에서는 겹치는 라벨을 숨긴다.

### 로즈(극좌표 꽃잎) 차트
- 축 = 분류 (3개 이상일 때만). 꽃잎 색 = 분류 색, 빈 칸 = `--fill-4`, 전체 평균 = `--label` 점선.
- 크기 세 가지만: 220(서랍·카드) · 180(비교) · 120(작은 카드).
- 꽃잎과 범례 행은 서로 연결 (하나에 올리면 둘 다 강조). 축을 고르면 다른 꽃잎은 흐리게.
- 데이터가 기준(예: 15개)보다 적으면 빈 상태 문구 ("항목이 15개 넘으면 보여요"). 축이 3개 미만일 때도 조용히 사라지지 말고 같은 문구.

### 가로 막대
- 항목 이름 왼쪽, 막대 가운데, 값 오른쪽 (`tabular-nums`). 트랙 `--fill-3`, 높이 6, 끝은 완전 둥글게.
- 막대 색 = 그 항목의 색 (분류면 분류 색). 많이 → 적게 순서.

### 비교 막대
- 가운데 축을 기준으로 두 대상이 양쪽. 막대 색 = 두 대상의 색. 큰 쪽 값을 굵게.

### 쌓은 막대 (예: 기간별 관심 변화)
- 100% 가로 막대, 기간마다 한 줄 (전체 기간이면 큰 기간마다, 기간 하나를 고르면 그 안의 달마다). 상위 6개 분류만 색, 나머지는 "기타"(`--fill`), 태그 없음은 `--gray`.
- 범례 칩을 누르면 아래 목록이 걸러진다 — 막대 칸을 눌러도 같다.
- 데이터가 없으면 "—" 대신 빈 상태 문구.

### 히트맵 달력
- 칸 = 하루 (필요하면 평일만). 칸 색 = 계열 색(사용자 색 또는 강조색), 진하기 = 그날의 개수. 진하기는 요소 투명도 대신 `color-mix()`로 (고대비·다크에서 바탕과 섞이지 않게).
- 공휴일 = 빨간 테두리, 쉬는 날 = 회색 빗금, 오늘 = `--label` 테두리.
- 범례(적음 → 많음), 월 표시, 연속 기록 문구. 칸을 누르면 그날의 툴팁 + 동작("이 날짜로 추가").

### 진행 막대 (목표 대비)
- 트랙 `--fill-3`, 채움 강조색(완료는 `--success`). 높이 4–8.
- 표시선: 70%(`--separator`), 90%(`--star`), "지금쯤 이만큼" 표시는 `--label`.

### 스파크라인
- 큰 숫자 뒤의 옅은 배경 그림. 계열 색 28% 채움, 축·라벨 없음. 데이터가 없으면 그리지 않는다 (장식이므로 빈 상태 불필요).

## 5. 공통 규칙

**범례**
- 계열이 둘 이상이면 항상 범례. 범례 항목 = 색 점 + 이름 + (선택) 개수.
- 범례 항목을 누르면 **그 계열만 보기**로 통일한다 (그래프·로즈·쌓은 막대 모두).
- 폰에서는 범례를 차트 아래 전체 폭으로 둔다 (이름이 잘리지 않게).

**툴팁** — 하나의 컴포넌트 `.ui-tooltip`
- 진한 유리, 둥글기 8, 안쪽 여백 8·10. 제목(Headline) + 값 줄(Callout).
- 마우스: 올리면 나타남. 터치: 탭하면 나타나고 다른 곳을 탭하면 사라짐. 클릭으로 고정할 수 있는 툴팁(달력)은 고정 상태에서 동작 버튼을 보여 준다.
- SVG `<title>`은 접근성 이름으로만 쓰고 툴팁으로 쓰지 않는다.

**빈 상태**
- 데이터가 모자라면 차트 자리에 `.ui-empty.compact`로 언제 보이는지 알려 준다. 빈 문자열 `""`이나 "—"를 돌려주지 않는다.

**접근성**
- 색만으로 구분하지 않는다: 범례 이름, 호버 라벨, 필요하면 무늬(빗금)를 함께.
- 그래픽 대비 3:1 (선·점과 바탕).
- SVG에 `role="img"`와 요약 `aria-label` ("분류 A 12개, 분류 B 8개 …").
- 동작 줄이기 설정이면 물리 애니메이션 없이 바로 배치, 타임랩스는 수동 넘기기로.
